Open Source RabbitMQ artifacts and Windows builds live in the `ossrabbitmq-rabbitmq-oss` repository — same access, same login as everything else. Follow [Navigating JFrog](/access/navigating-jfrog) and [Discover Versions](/access/discover-versions) to browse and download.

## Windows builds

Windows builds are available to AceMQ customers from the same repository:

```
rabbitmq-server-<version>.exe          # full installer
rabbitmq-server-windows-<version>.zip  # zip distribution
```

Browse to **Artifacts → `ossrabbitmq-rabbitmq-oss` → `<version>`** and download the installer or zip directly — no token needed for a browser download.

<Callout kind="alert">

**AceMQ Insight**

AceMQ has commercial customers running Windows estates in production, and commercial features including Warm Standby Replication work on Windows. If you need a specific Windows version that isn't showing in the repository, ask — some Windows builds are pulled into the local repo on request rather than proxied automatically. See [Getting Help](/support/getting-help).

</Callout>

### Windows deployment notes

See the AceMQ Premium knowledge base or your support contact for Windows-specific operational guidance. Two things worth knowing before you start:

- **EDR/antivirus exclusions.** Endpoint protection commonly blocks `rabbitmqctl` and `rabbitmq-diagnostics`. Exclude the Erlang OTP and RabbitMQ server directories **and all subdirectories**.
- **Environment variables.** After changing `ERLANG_HOME`, `RABBITMQ_SERVER`, or `RABBITMQ_BASE`, reinstall the service (`rabbitmq-service.bat stop` → `remove` → `install` → `start`) and verify with `echo %RABBITMQ_BASE%`.

## Open Source builds

The community build is available in the same repository for evaluation or for deployments that deliberately don't need LTS support or commercial plugins.

Without a commercial license, **3.13.7 is the newest freely available build** — see [What Is Tanzu?](/start-here/what-is-tanzu) for what a license adds beyond that.
