Open Source RabbitMQ artifacts live in the same `ossrabbitmq-rabbitmq-oss` repository as the licensed Tanzu builds — same access, same login, no separate entitlement needed. Follow [Navigating JFrog](/access/navigating-jfrog) and [Discover Versions](/access/discover-versions) to browse and download.

## Windows

<Callout kind="warning">

**Tanzu RabbitMQ is not distributed for Windows.** The only Windows artifacts available are plain Open Source builds (`rabbitmq-server-<version>.exe` and `-windows-<version>.zip`) — there is no `tanzu-rabbitmq` Windows package. If you need RabbitMQ on Windows, you are running the unlicensed community build, not a licensed Tanzu artifact, regardless of your license status for other formats.

</Callout>

AceMQ support still covers Windows deployments under your commercial support agreement — licensing just doesn't change what's available for that platform.

## Why you might use this

- You're evaluating before licensing
- You specifically need Windows
- You're running the community edition deliberately and don't need LTS support or commercial plugins

See [What Is Tanzu?](/start-here/what-is-tanzu) for what a license actually adds over this build.
