## No license key

There is no separate license key to install or configure. **The license is embedded in the commercial builds you pull from the AceMQ JFrog repository.** As long as you're running packages pulled from `acemq.jfrog.io`, you're licensed. See [Get Your Packages](/packages/oci).

## Package formats covered

Your entitlement covers Tanzu RabbitMQ in every format AceMQ distributes:

- **OCI container images** — Docker, Podman, containerd
- **RPM** — Red Hat Enterprise Linux 8 and 9
- **OVA** — VMware virtual appliance, including a FIPS variant
- **Kubernetes** — Helm chart and operator images
- **Windows** — installer and zip distribution
- **Open Source RabbitMQ** — the community build, also available through the same repository

Not sure which to use? See [Choose a Format](/start-here/choose-a-format).

## Commercial features

Your license unlocks the commercial-only plugins — Warm Standby Replication, Delayed Queues, Intra-cluster Compression, AMQP 1.0 over WebSocket, OAuth 2.0 extensions, LDAP runtime configuration, and Distributed Shovels. See [Exclusive Features](/docs/features/availability-matrix) for what's available in which version.

## Support

AceMQ support covers all RabbitMQ — Bitnami/open-source or Tanzu, any release — under your agreement. Licensing specifically adds:

- Access to LTS-supported and newer commercial builds (the free community ceiling is 3.13.7)
- The commercial-only plugins above
- Jump upgrades across versions
- A standard 12-hour response time on product-related issues
