## No license key

There is no separate license key to install or configure. **The license is embedded in the commercial builds you pull from the AceMQ JFrog repository.** As long as you're running packages pulled from `acemq.jfrog.io`, you're licensed. See [Get Your Packages](/packages/oci) for how to pull them.

## Package formats covered

Your entitlement covers Tanzu RabbitMQ in every format AceMQ distributes:

- **OCI container images** — Docker, Podman, containerd
- **RPM** — Red Hat Enterprise Linux 8 and 9
- **OVA** — VMware virtual appliance, including a FIPS variant
- **Kubernetes** — Helm chart and operator images
- **Open Source RabbitMQ** — the unlicensed community build, also available through the same repository

<Callout kind="warning">

A licensed Tanzu build is not distributed for Windows. Windows deployments use Open Source RabbitMQ — see [Open Source RabbitMQ](/packages/open-source).

</Callout>

## Core counting

Licensing is priced per core. **Non-production cores count the same as production cores.** If you run dev, staging, and prod environments, your core count must include all of them — not just production.

## Support

AceMQ support covers all RabbitMQ — Bitnami/open-source or Tanzu, any release — under your SLA. Licensing specifically adds:

- Access to LTS-supported and newer commercial builds
- A standard 12-hour response time on product-related issues
- A discount on emergency escalation and incident-management contracts, if you need faster response

See [Licensing FAQ](/support/licensing-faq) for more, and [Getting Help](/support/getting-help) for how to open a ticket.
