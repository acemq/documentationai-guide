## Recent Releases

## Upgrading Your Knowledge Base

Follow these steps to apply the latest updates to your local or deployed documentation site.

<Steps>
  <Step title="Backup Current Site" icon="database">
    Create a backup of your current documentation repository.
  </Step>
  <Step title="Pull Latest Changes" icon="git-pull-request">
````bash
git pull origin main
npm install
````
  </Step>
  <Step title="Verify Configurations" icon="settings">
    Check `rabbitmq.conf` for any deprecated settings from the changelog.
  </Step>
  <Step title="Deploy Updates" icon="rocket">
    Build and redeploy your static site or Tanzu-hosted docs.
  </Step>
</Steps>

For configuration migrations between versions, see the examples below.

<CodeGroup tabs="Tanzu RabbitMQ 1.2,Tanzu RabbitMQ 1.3">
````yaml
# Tanzu RabbitMQ 1.2 Operator Config
apiVersion: rabbitmq.com/v1beta1
kind: RabbitmqCluster
metadata:
  name: prod-cluster
spec:
  replicas: 3
  rabbitmq:
    additionalConfig: |
      quorum_queue.default = true
````
````yaml
# Tanzu RabbitMQ 1.3 Operator Config (Updated)
apiVersion: rabbitmq.com/v1beta1
kind: RabbitmqCluster
metadata:
  name: prod-cluster
spec:
  replicas: 3
  rabbitmq:
    additionalConfig: |
      quorum_queue.default = true
      stream.enabled = true
````
</CodeGroup>
