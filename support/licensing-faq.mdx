title: Licensing FAQ
description: Common questions about what an AceMQ Tanzu RabbitMQ license covers.
---

### Do I need a license key?

No. The license is embedded in the commercial build you pull from `acemq.jfrog.io`. See [Licensing](/access/licensing).

### Does my support cover our existing Bitnami/open-source deployment?

Yes. AceMQ support covers all RabbitMQ deployments — Bitnami, open-source, or Tanzu — under your SLA. Licensing adds LTS support and access to newer commercial builds; it doesn't gate support for what you're already running.

### How is licensing priced?

Per core, and **pre-production cores count the same as production cores.** Include every environment when sizing.

### What does "Tanzu" actually mean?

See [What Is Tanzu?](/start-here/what-is-tanzu) — it's the most commonly misunderstood term in this whole process.

### Which package formats does my license cover?

All of them — OCI, RPM, OVA, Kubernetes, and Open Source. See [What's Included](/start-here/whats-included).

### Is Windows covered?

AceMQ support covers Windows deployments, but there is no licensed Tanzu package for Windows — only the Open Source build. See [Open Source RabbitMQ](/packages/open-source).

### How long is my version supported?

See [Version Support Matrix](/start-here/version-support-matrix) for stream-level dates, and [Version & Support Policy](/support/version-policy) for the separate rule about which minor release is actually current.
