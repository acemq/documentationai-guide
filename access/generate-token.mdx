---
title: Generate a Token
description: Create a scoped JFrog identity token to authenticate Docker, Helm, and repository pulls.
---

You need a token to authenticate `docker login`, `helm`, and repository pulls. Your JFrog username alone is not a password.

<Steps>
  <Step title="Open your user profile" icon="user">

  Log in to `acemq.jfrog.io`, click your username in the upper right, and select **Edit Profile**.

  </Step>
  <Step title="Generate an identity token" icon="key">

  Open the **Identity Tokens** section and click **Generate Token**. Set an expiration that matches your organization's secret-rotation policy.

  <Callout kind="warning">

  A token created outside the user profile page (for example, through certain API calls) can fail to bind correctly to your account, producing a *"Binding token to existing user ... is allowed only through the user profile page"* error. Always generate it from the profile page.

  </Callout>

  </Step>
  <Step title="Scope it to every repository you'll use" icon="layers">

<Callout kind="alert">

**AceMQ Insight**

Don't scope the token to `rabbitmq-docker-remote` alone. That covers container images only — a token scoped that narrowly **cannot pull RPMs, OVAs, Helm charts, or operator images**, and produces confusing permission errors that look like an entitlement problem rather than a token-scope problem. Scope it across every repository you actually use:

| Repository | Needed for |
|---|---|
| `rabbitmq-docker-remote` | Broker container images |
| `ossrabbitmq-rabbitmq-oss` | RPM, OVA, tarballs, Open Source builds |
| `rabbitmq-helmoci-remote` / `helm-remote` | Kubernetes Helm chart |
| `rabbitmq-operator-docker-remote` | Kubernetes operator images |

</Callout>

Container and Helm pulls also need **deploy** permission, not just read — see [Your JFrog Account](/access/jfrog-account).

  </Step>
  <Step title="Copy it immediately" icon="copy">

  JFrog displays the token only once. Store it in a secrets manager — never commit it to source control.

  </Step>
</Steps>

## Using the token

The token is your password. Your JFrog username is your username:

```bash
docker login acemq.jfrog.io
# Username: <your JFrog username>
# Password: <paste the token>
```

See [OCI / Containers](/packages/oci) to continue with your first pull.
