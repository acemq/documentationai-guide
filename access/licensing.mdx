## No license key

There is no license key file, environment variable, or config setting to apply. **The license is embedded in the commercial build itself.** If you pulled it from `acemq.jfrog.io`, you're licensed to run it.

## Core counting

Licensing is priced per core, and **pre-production cores are counted the same as production cores.** When sizing your license, include every environment — dev, staging, DR, and prod.

## Support tiers

All licensed customers receive:

- Commercial support covering all RabbitMQ deployments (Bitnami/open-source or Tanzu)
- A standard 12-hour response time on product-related issues

Customers who need faster response for production incidents can add an emergency escalation and incident-management contract, at a discount for licensed customers.

See [Getting Help](/support/getting-help) to open a ticket, and [Licensing FAQ](/support/licensing-faq) for common questions.
