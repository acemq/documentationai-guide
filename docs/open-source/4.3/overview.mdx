Open Source RabbitMQ 4.3 is the freely available community build — the same core as Tanzu RabbitMQ, without the commercial plugins or LTS support commitment. See [What Is Tanzu?](/start-here/what-is-tanzu) for the full distinction.

## Erlang/OTP compatibility

| OTP version | Status |
|---|---|
| 26, 27 | Fully supported |
| 28 | Partially supported, and **not certified on 4.3** |

<Callout kind="alert">

**AceMQ Insight**

Erlang 28 is only supported for brand-new clusters — upgrading a Khepri-enabled cluster from Erlang 27 to 28 has a known issue affecting rolling upgrades. Stay on Erlang 27 for existing clusters until this is resolved upstream.

</Callout>
