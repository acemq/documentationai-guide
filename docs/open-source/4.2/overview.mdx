Same Erlang/OTP compatibility as [Open Source 4.3](/docs/open-source/4.3/overview): OTP 26 and 27 fully supported, OTP 28 partially supported and only for brand-new clusters.

See [Get Open Source RabbitMQ](/packages/open-source) to download.
