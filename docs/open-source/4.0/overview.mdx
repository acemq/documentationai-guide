## Erlang/OTP compatibility

<Callout kind="warning">

**Erlang 26 reached end of life partway through this stream.** Starting with the 4.0.23 patch, the minimum supported Erlang version is 27.0. Nodes fail to start on older Erlang releases — check your Erlang version before applying a patch upgrade.

</Callout>

| OTP version | Status |
|---|---|
| 26 | Supported on patches before 4.0.23; EOL as of 4.0.23 |
| 27 | Required from 4.0.23 onward |
