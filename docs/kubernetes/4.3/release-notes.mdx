This page summarizes the 4.3.x series at a high level. For the full patch-by-patch changelog, check the version-specific notes when you pull — or ask AceMQ support.

## 4.3.0 — major release highlights

- Khepri enabled by default for new clusters
- Distributed Shovels
- Delayed and scheduled messaging, generally available
- OAuth 2.0 opaque token support
- SQL filter expression for Streams
- Direct Reply-To for AMQP 1.0
- Automated blue-green migration tooling from 3.13.x clusters
- Incoming/outgoing message interceptors for AMQP 1.0, AMQP 0-9-1, MQTTv3, MQTTv5
- Local shovels, WebSocket optimization

## Subsequent patches

Each patch in the 4.3.x series (4.3.1, 4.3.2, 4.3.4, and later) carries incremental bug fixes and security fixes. See [Security Fixes](/docs/kubernetes/4.3/security-fixes) and [Known Issues](/docs/kubernetes/4.3/known-issues) for what to check before and after upgrading between patches.
