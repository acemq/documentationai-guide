title: Kubernetes 4.3 Security Fixes
description: Security fixes shipped in Tanzu RabbitMQ for Kubernetes 4.3 patch releases.
---

Security fixes are shipped per patch release within the 4.3.x stream. For the current list of CVEs addressed in the patch you're running, check the [Release Notes](/docs/kubernetes/4.3/release-notes) for that specific version, or ask AceMQ support for a CVE summary against your running version — see [Getting Help](/support/getting-help).

<Callout kind="alert">

**AceMQ Insight**

CVE questions are one of the most common recurring requests AceMQ sees from licensed customers. If you need a CVE report for a compliance review, ask — AceMQ can provide one against your specific running version faster than cross-referencing patch notes yourself.

</Callout>

## Staying current

Because only the current minor of a supported stream is the actively Tanzu-licensed build (see [Version & Support Policy](/support/version-policy)), staying on the latest 4.3.x patch is also how you stay current on security fixes. Check [Discover Versions](/access/discover-versions) for how to find the latest available patch.
