## Staying current

Because only the current minor of a supported stream is the actively Tanzu-licensed build (see [Version & Support Policy](/support/version-policy)), staying on the latest 4.3.x patch is also how you stay current on security fixes. Check [Discover Versions](/access/discover-versions) for how to find the latest available patch.
