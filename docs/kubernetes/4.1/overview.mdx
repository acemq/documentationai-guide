---
title: Kubernetes 4.1 Overview & Install
description: Tanzu RabbitMQ on Kubernetes 4.1 — supported through April 2027.
---

<Callout kind="info">

4.1 is supported through 30 April 2027 — shorter remaining support than 4.2, 3.13, or 4.3. See [Version Support Matrix](/start-here/version-support-matrix). If you're starting a new deployment, AceMQ recommends [4.2](/docs/kubernetes/4.2/overview) instead.

</Callout>

Installation follows the same pattern as [Kubernetes 4.3](/docs/kubernetes/4.3/install) — the `tanzu-rabbitmq-operators` chart, then a `RabbitmqCluster` resource pointing at the 4.1.x image tag.

See [Get the Kubernetes Package](/packages/kubernetes) to pull it, and [Known Issues](/docs/kubernetes/4.1/known-issues) before upgrading onto or off of this stream.
