<Callout kind="warning">

**4.0 reaches end of commercial support on 30 September 2026.** If you're running 4.0, start planning your move to [4.2](/docs/kubernetes/4.2/overview) or [4.3](/docs/kubernetes/4.3/overview) now — see [Version Upgrades](/migrations/version-upgrades) and [Version Support Matrix](/start-here/version-support-matrix).

</Callout>

Installation follows the same pattern as [Kubernetes 4.3](/docs/kubernetes/4.3/install), substituting the 4.0.x chart and image tags. See [Get the Kubernetes Package](/packages/kubernetes).
