---
title: Kubernetes 4.2 Troubleshooting
description: Common issues and fixes for Tanzu RabbitMQ on Kubernetes 4.2.
---

Same troubleshooting patterns as [Kubernetes 4.3 → Troubleshooting](/docs/kubernetes/4.3/troubleshooting): check [Access Troubleshooting](/support/access-troubleshooting) first for any image pull failure, verify pod anti-affinity and topology-as-code for "queues missing after redeploy," and check readiness-probe resource limits for a stuck rolling upgrade.
