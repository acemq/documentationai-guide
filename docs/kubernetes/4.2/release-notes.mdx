## 4.2.0 — highlights

- Improved Raft handling for quorum queues
- SQL filter expressions for Streams
- Warm Standby Replication moved to CRD-based configuration; the standalone Standby Replication Operator was removed
- OAuth 2.0 forward proxy support
- LDAP runtime configuration changes

## Subsequent patches

The 4.2.x series has continued receiving security and bug fixes through at least 4.2.9. See [Discover Versions](/access/discover-versions) for how to find the current patch, and ask AceMQ support for a CVE summary against your running version if needed for compliance.
