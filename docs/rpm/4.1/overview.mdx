Same install pattern as [RPM 4.3](/docs/rpm/4.3/install) — no YUM repo, direct file download, same three prerequisites. See [Version Support Matrix](/start-here/version-support-matrix) — 4.1 is supported through 30 April 2027; AceMQ recommends [4.2](/docs/rpm/4.2/overview) for new deployments.

See [Get the RPM Package](/packages/rpm) for the download path.
