## Run

Same run pattern as [OCI 4.3 → Run](/docs/oci/4.3/run) — substitute the `4.1.14` tag:

```bash
docker run -d --name rabbitmq \
  -p 4369:4369 -p 5672:5672 -p 15672:15672 -p 25672:25672 \
  -v /data/rabbitmq/data:/var/lib/rabbitmq/ \
  -e RABBITMQ_ERLANG_COOKIE=<your-cookie> \
  -h rmq1 \
  acemq.jfrog.io/rabbitmq-docker-remote/vmware-tanzu-rabbitmq:4.1.14
```
