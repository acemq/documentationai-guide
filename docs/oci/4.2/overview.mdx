4.2 is AceMQ's recommended LTS stream — see [Kubernetes 4.2 Overview](/docs/kubernetes/4.2/overview) for why. The OCI image on 4.2 carries the same broker as the Kubernetes and OVA formats; only the packaging differs.

<Callout kind="alert">

**AceMQ Insight**

If you have Kubernetes available, use it — see [Kubernetes 4.2](/docs/kubernetes/4.2/overview). Use the standalone OCI image only when you don't have a Kubernetes environment.

</Callout>

See [Get the OCI / Container Package](/packages/oci) to pull it.
