**4.0 commercial support ends 30 September 2026.** If that date has passed, this stream is unsupported. See [Version Support Matrix](/start-here/version-support-matrix) and move to [4.2](/docs/oci/4.2/overview) — see [Version Upgrades](/migrations/version-upgrades).

</Callout>

## What ships in 4.0.24

| Component | Version |
|---|---|
| Tanzu RabbitMQ | 4.0.24 (based on open-source RabbitMQ 4.0.24) |
| Erlang | 27.3.4.16 |

<Callout kind="warning">

**Erlang 26 reached end of life partway through this stream.** Starting with the RabbitMQ 4.0.23 patch, the minimum supported Erlang version is 27.0 — nodes fail to start on older Erlang releases. If you're running an older 4.0.x patch on Erlang 26, upgrading the broker patch requires upgrading Erlang first.

</Callout>

## Run

Same run pattern as [OCI 4.3 → Run](/docs/oci/4.3/run) — substitute the `4.0.24` tag:

```bash
docker run -d --name rabbitmq \
  -p 4369:4369 -p 5672:5672 -p 15672:15672 -p 25672:25672 \
  -v /data/rabbitmq/data:/var/lib/rabbitmq/ \
  -e RABBITMQ_ERLANG_COOKIE=<your-cookie> \
  -h rmq1 \
  acemq.jfrog.io/rabbitmq-docker-remote/vmware-tanzu-rabbitmq:4.0.24
```
